# 👾 Ghost Dashboard

Минималистичный, высокопроизводительный командный центр для **Arch Linux & Hyprland** (Wayland) в темной палитре **VS Code Dark+**.

Разработан специально под вертикальные мониторы и многоэкранные сетапы.

---

## ⚡ Особенности и возможности

- **👾 60 FPS Canvas Pacman:** Анимированный холст с Пакманом, охотящимся за призраком через всё пространство окна.
- **📅 Интерактивный Календарь:** Сетка месяца с американским форматом недели (Вс–Сб), поддержкой локализации и постоянными заметками (`JSON`).
- **📊 Телеметрия Железа (Многопоточная):**
  - Опрос температуры и нагрузки **AMD Ryzen 7 (Zen 4 / AM5)** через драйвер ядра `k10temp`.
  - Мониторинг частот, температуры и VRAM для **NVIDIA GeForce RTX (50xx/40xx)** через `nvidia-smi`.
  - Живой мониторинг сетевых интерфейсов (Ethernet, Wi-Fi, Tailscale) с замером скорости отдачи и скачивания.
- **🔊 Нативный Микшер PipeWire (Playback Streams):**
  - Управление звуком каждого запущенного приложения отдельно (Chrome, Discord, игры) прямо как в Pavucontrol.
  - Мгновенная реакция без лагов через асинхронный вызов `wpctl` / `pactl`.
- **🎯 War Thunder Control:** Быстрый запуск игры и кнопка экстренного завершения зависших процессов (`kill -9 aces`).
- **🚀 Лаунчер и Диспетчер процессов:** Автоматическое сканирование всех установленных приложений в системе (`.desktop`) с живым поиском и встроенным Task Killer.

## 🛠 Установка и Запуск

```bash
# 1. Установка системных пакетов (Arch Linux)
sudo pacman -S --needed python tk python-psutil

# 2. Установка CustomTkinter
pip install customtkinter --break-system-packages

# 3. Запуск
python main.py
🖥 Интеграция в Hyprland (Lua)
В ~/.config/hypr/hyprland.lua:
code
Lua
hl.window_rule({
    name  = "ghost-dashboard",
    match = { title = "Ghost Dashboard" },
    float = false,
})

hl.bind(mainMod .. " + D", hl.dsp.exec_cmd("python ~/ghost-dashboard/main.py"))
